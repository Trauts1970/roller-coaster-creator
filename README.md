# Roller Coaster Creator

A Steam Deck-first 3D roller coaster construction and simulation game.

## Design goals
- Automatic sequential track assembly is the default; optional manual 3D editing.
- Test runs distinguish physically traversable track from passenger-safe track.
- First-person ride and external replay cameras.
- Godot 4 project; Linux/Steam Deck target.
- No GitHub Actions workflows by default. Use local builds and publish validated, versioned packages only when ready.

## Current state
Planning/scaffold only. No playable build or Steam Deck test has been completed.

Development work belongs on `dev/roller-coaster-v0.1`. Dashboard status is published separately to `main`.
